# Люберцы Вет / Next — концепт редизайна «Future of Care»

Отдельный демонстрационный проект. Действующий сайт люберцы-вет.рф не изменялся.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5199
npm run build      # статическая сборка в dist/ (+ пререндер страниц услуг)
npm run preview    # просмотр сборки
```

`?nointro` в адресе пропускает интро-прелоадер (удобно при разработке).

## Стек

Vite + TypeScript без фреймворка. GSAP (ScrollTrigger, SplitText, Flip), Lenis, собственное ядро WebGL
(`src/gl/gl.ts`) с GLSL-шейдерами. Шрифты — Unbounded / Manrope / JetBrains Mono (variable, кириллица, self-hosted).

## Концепция

**«Животное — главный герой».** Тёмная кинематографичная сцена с вырезанной (Apple Vision, `tools/cutout.swift`)
фотографией собаки: слово «ЗАБОТА.» стоит *за* ней, «БЛИЖЕ, ЧЕМ КАЖЕТСЯ.» — *перед* ней.
Дальше ритм чередует светлые редакционные сцены (Warm Ivory) и тёмные «технологичные» (Almost Black),
а Electric Lime появляется только в индикаторах, активных состояниях и точках-акцентах.
Вместо карточек — строки каталога, консоль, топографическая карта и крупная типографика.

## Работающие сложные эффекты

| Где | Что |
|---|---|
| Интро | Счётчик 000→100, привязанный к реальной загрузке фото и шрифтов, уход шторкой |
| Hero | Раскрытие собаки круглой маской из точки у глаз, буквы поднимаются от центра, прыжок лаймовой точки |
| Hero | Трёхслойный параллакс по курсору (фон, собака, передний текст, «прицел» осмотра) |
| Hero | Variable font: буквы рядом с курсором становятся жирнее (wght 260→880) |
| Hero → Манифест | Закреплённая сцена: собака приближается, слова разъезжаются, следующая сцена раскрывается растущей маской |
| Манифест | Слова проявляются по мере прокрутки |
| Кошки / Собаки | **WebGL-переход**: fbm-растворение с displacement, хроматическая аберрация и лаймовая кромка на фронте; drag/swipe по фото ведёт прогресс перехода «пальцем»; разный темп микроанимаций у режимов |
| Услуги | **WebGL-превью у курсора** с волновым искажением и RGB-сдвигом по скорости мыши, раскрытие по шумовой маске; аккордеон с подробностями и переход на страницу услуги |
| Как проходит вызов | Закреплённая сцена на ~3 экрана: маски кадров с перспективой, кинетика букв, счётчик-барабан, смена палитры, прогресс; работает и при прокрутке назад |
| Помощник | 4-шаговая консоль, итоговая фраза с правильными падежами, копирование текста обращения, `tel:` |
| География | **Шейдерная топография** (изолинии из шума, реагирует на курсор) + схема районов как диаграмма Вороного |
| Цены | Живой поиск (ё=е, подсветка совпадений), категории, сортировка, FLIP-анимации, аккордеон пояснений |
| Editorial / Срочно / Финал | Раскрытие слов в перспективе, раскрытие через насыщенность шрифта, линия «пульса» по скроллу, параллакс кадров |
| Система | Курсор с состояниями (ссылка / открыть / тянуть / прицел / текст), магнитные кнопки, Lenis + ScrollTrigger, переходы-шторки между главной и страницами услуг с рабочей историей браузера |

## Адаптивность и доступность

- Отдельная мобильная композиция Hero, нижний док под большой палец (меню, услуги, цены, звонок), меню — нижний лист со свайпом вниз.
- Нет горизонтальной прокрутки на 375 / 768 / 1440 / 1920.
- Семантическая разметка, skip-link, видимый фокус, ловушка фокуса в меню, radio-группы в помощнике (Enter / «Далее» с клавиатуры), стрелки в переключателе животных.
- `prefers-reduced-motion`: без Lenis, интро, пинов и параллакса; история вызова становится обычным списком.
- WebGL рендерит только видимые секции и останавливается во фоновой вкладке; на слабых устройствах превью отключается, DPR ограничен.

## SEO

Весь контент в HTML ещё до запуска JS (пререндер из `src/data.ts` в Vite-плагине). Сохранены посадочные страницы
`/services/<slug>` — со своими title, description, canonical, h1. JSON-LD `VeterinaryCare`.

## Контент

Услуги, тексты страниц услуг, цены (с сохранением «от»), районы, режим работы и телефон взяты с люберцы-вет.рф (19.10.2026).
Отзывы, врачи, акции, координаты, время приезда и онлайн-запись не выдумывались.

## Известные ограничения

- Фотографии — Unsplash (лицензия Unsplash допускает коммерческое использование). Для продакшна лучше заменить на собственную съёмку.
- Проверка шла во встроенном браузере (десктоп 1440/1920, планшет 768, телефон 390). Окно было фоновым, поэтому кадры троттлились, и плавность анимаций на глаз не оценена. На реальных iOS/Android-устройствах не тестировалось.
- `raw/` — исходники фото и вырезки (в сборку не попадают).
- Ссылка «Политика конфиденциальности» ведёт на страницу действующего сайта.
